小黑盒Community For Mac 0.3.1

- 信息流默认以窄窗启动。打开文章时，详情在右侧展开，左侧列表保持原宽和滚动位置。信息流支持下拉刷新和滚动加载。
- 底部液态玻璃导航整合发现、动态、游戏、搜索、我的和更多入口。动态和作者主页的卡片可直接进入评论、收藏和关联游戏。
- 账号页新增个人主页、账号 ID 复制和本机历史。Steam 搜索可先预览所选游戏，再进入公告。
- 搜索页可直接切换全站、分区和话题，支持按原范围重放搜索、逐条删除历史，并区分 Steam 与小黑盒查询。
- 正文使用原生排版，优化中文长帖的分段、行距和行内表情。评论接在正文底部，楼中楼在原处展开。正文与评论图库支持缩略图切换、缩放和原图入口。
- 阅读设置即时预览字号、行高与段距。账号会话继续保存在本机加密文件中。
- Apple Silicon 和 Intel 安装包均采用 Apple Developer ID 签名与公证。
